## Featured project

### [Ephemres](https://github.com/dc8official/ephemres)
*Formerly LNMP (Linux Network Monitoring Platform)*

`FastAPI` `asyncio` `TimescaleDB` `Vue` `PrimeVue`

A network monitoring platform built from scratch and running on a production network, now at v3.0. It tracks endpoint state over time and uses mean and standard deviation baselines to decide what counts as abnormal for each target. It also doubles as the backbone of a structured Python curriculum, so the code gets studied as carefully as it gets deployed.

**In progress**
- A reduced-package build that is lighter and faster to install
- A small on-device model (under 2B parameters) to sharpen root cause analysis, topology rendering and anomaly detection, trained on synthetic data derived from the production deployment
